# 01 · 产品定义

## 一句话

**Steward 是你的个人数字资产台账**：卡、云、家，一处看清，敏感数据只留在自己手里。

## 要解决的问题

个人的「数字资产」天然分散在三个互不相通的世界里，而且每个世界都只给你看自己那一块：

| 领域 | 现状 | 痛点 |
| --- | --- | --- |
| 银行 / 信用卡 | 每家银行一个 App，账单按月推 | 待还金额、还款日、免息期分散在 5–10 个 App 里，容易漏还；额度使用率看不全 |
| 多云主机 | 阿里云、腾讯云、AWS 各有控制台 | 忘记续费的包年实例、闲置却还在计费的机器；跨云成本无法横向比较 |
| 智能家居 | 米家、HomeKit、涂鸦、HA 各一套 | 设备状态与账号体系碎片化 |

现有替代方案要么太重（云厂商 FinOps 平台面向企业），要么太散（备忘录、Excel），
要么把最敏感的数据放到别人服务器上（记账 App 的云同步）。

## 目标用户

**第一用户画像**：有 3 张以上银行卡 + 2 个以上云账号 + 一套智能家居的独立开发者 / 小团队负责人。
特征：愿意自托管、对数据主权敏感、能接受「先配置再用」的一次性成本。

**明确不服务**：需要多人协作记账的家庭、需要发票/报销流程的小微企业财务。

## 三个模块的价值与边界

### 1. 卡包（MVP 首发）

- **做**：卡片台账、额度与余额、账单导入与解析、还款日提醒、额度使用率。
- **不做**：代还、代扣、自动登录银行、抓取短信验证码。这些要么涉及支付牌照，要么需要托管银行密码，风险与合规成本远高于收益。
- **为什么靠导入**：国内没有面向个人的开放银行 API。银行 App 导出 CSV/PDF 是唯一稳定、合规的数据来源。因此解析器必须**容错优先**：一行失败不能毁掉整份账单。

### 2. 多云主机（MVP 第二块）

- **做**：只读盘点 + 开关机 + 成本汇总 + 到期提醒。
- **不做**：创建/销毁实例、改安全组、跑脚本。破坏性操作在 v1 之前不开放，避免误删生产机。
- **关键体验**：一张表看完「谁在跑、谁在烧钱、谁快到期」。

### 3. 智能家居（v2）

- **做**：通过 **Home Assistant** 统一接入（一次对接覆盖米家 / 涂鸦 / HomeKit / Matter），展示设备状态、执行场景。
- **不做**：自研各厂商协议、做网关硬件。
- **理由**：逐家对接是无底洞；HA 已经解决了 90% 的适配问题，且同样可自托管，与产品气质一致。

## MVP 范围与验收标准

### 范围（v0.1，已完成骨架）

1. 四端可运行：桌面（macOS/Win/Linux）、iOS、Android 同一套前端。
2. 本地数据闭环：新增卡片 → 导入账单 → 总览看到待还与使用率。
3. 云账号绑定 → 拉取主机 → 开关机 → 成本汇总（Mock 数据）。
4. 自建同步：两台设备配对、端到端加密、LWW 合并。

### 验收标准（可测）

- [ ] 导入一份 200 行的招商银行 CSV，成功 ≥ 195 行，失败行有明确原因。
- [ ] 断网时所有页面可用，不出现 loading 卡死。
- [ ] 同步后服务器数据库里 `grep` 不到任何卡号、商户名、IP。
- [ ] 新设备凭「Vault ID + 配对码 + 同步口令」在 60 秒内完成首次同步。
- [ ] 冷启动到总览可交互 < 1.5s（M1 桌面端实测）。

## 非目标（至少一年内）

- 不做记账/分类预算（那是另一条产品线）。
- 不做投资组合与行情。
- 不做家庭共享账本（多用户权限会显著抬高同步与加密复杂度）。
- 不做 SaaS 托管版，只提供自托管。

## 与替代方案的差异

| 方案 | 差异 |
| --- | --- |
| 银行 App / 云控制台 | 只能看自家；Steward 做的是**跨源聚合** |
| Excel / Notion 模板 | 无加密、无提醒、无 API 拉取，且手工维护成本高 |
| 记账 App（随手记等） | 数据在厂商云上；Steward 端到端加密 + 自托管 |
| Home Assistant | 只管智能家居；Steward 把卡与云也纳入同一视图 |

## 指标

北极星指标：**周活跃的「资产视图完整度」**——用户绑定的数据源中，最近 7 天成功刷新过的比例。

辅助指标：

- 首次价值时间（安装 → 第一张卡 + 第一期账单）< 5 分钟。
- 账单导入成功率（行级）> 95%。
- 同步失败率 < 1%。
- D30 留存（钱包类产品通常 20–30%，自托管工具型可到 40%）。

## 商业化（暂不实施，仅记录选项）

1. 开源核心 + 付费的托管同步/备份服务（但会削弱「自托管」卖点）。
2. 团队版：多人共享云账号成本视图。
3. 一次性买断（Mac App Store / 独立分发）。
